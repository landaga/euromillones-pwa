EUROMILLONES PWA v1
===================

PRUEBA EN EL PC
1. Descomprime esta carpeta.
2. Haz doble clic en INICIAR_APP.bat.
3. Se abrirá http://localhost:8080 en el navegador.
4. Pulsa "Actualizar histórico".
5. Ya puedes generar 3 apuestas, ver estadísticas y ejecutar backtesting.

FUNCIONES
- Histórico completo de Euromillones desde 2004.
- Actualización online.
- Carga manual de CSV.
- 3 apuestas propuestas.
- Frecuencias y retrasos.
- Backtesting walk-forward frente al azar.
- Respeta las eras de 9, 11 y 12 estrellas.
- Guarda las apuestas en el propio dispositivo.
- PWA preparada para instalar en móvil cuando se publique mediante HTTPS.

FUENTE DE DATOS
https://raw.githubusercontent.com/daowa89/lottery-archive/main/eu/euromillions/results.csv

NOTA
El algoritmo no predice sorteos. Todas las combinaciones válidas tienen la misma probabilidad matemática.
